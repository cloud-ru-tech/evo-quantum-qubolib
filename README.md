# qubo_lib: Python Framework for QUBO

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://www.python.org/downloads/)
[![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)
[![CUDA](https://img.shields.io/badge/CUDA-12.8-green)](https://developer.nvidia.com/cuda)

`qubo_lib` — это Python-библиотека для исследования и решения задач QUBO, ключевой формулировки для квантовых алгоритмов оптимизации. Библиотека предоставляет унифицированный интерфейс для различных типов задач и солверов, позволяя быстро проводить эксперименты, сравнивать алгоритмы и делать исследования воспроизводимыми.

## 📦 Установка и быстрый старт

### CPU версия 
```bash
pip install git+https://github.com/cloud-ru-tech/evo-quantum-qubolib.git
```

### GPU версия
Требуется CUDA Toolkit.
```bash
pip install "qubo_lib[gpu]@git+github.com/cloud-ru-tech/evo-quantum-qubolib.git"
```

Решим задачу коммивояжера (TSP) двумя разными способами: эвристикой на GPU и полным перебором.

```python
from qubo_lib.problems import TSP
from qubo_lib.solvers import MSSA, QBF, Parallel

# Создаем случайную задачу TSP (7 городов -> 49 QUBO-неизвестных)
problem = TSP.init_random_instance(seed=42, n_cities=7)

# Решаем полным перебором на двух GPU
solution_bf = Parallel(base_solver=QBF, splits_cnt=2, devices=['cuda']*2).solve(problem)
print(solution_bf)
```
Больше примеров в ноутбуке showcase.ipynb

## ✨ Возможности

*   **Единый API**: Одинаковый способ запуска для любой задачи и любого солвера.
*   **Высокопроизводительные солверы**: Эффективный брутфорс и имитационный отжиг на GPU.
*   **Расширяемость**: Простое добавление новых задач и солверов через наследование от базовых классов.
*   **Воспроизводимость**: Класс `Solution` сохраняет все параметры эксперимента.
*   **Экономия памяти**: "Ленивое" построение матрицы Q только при необходимости.

## 🚀 Полная версия в нашем облаке

Библиотека доступна в двух вариантах. Open-source версия включает в себя базовый функционал и солверы `QBF` и `Parallel`.

Для доступа к самым производительным солверам, включая `MSSA` (GPU-ускоренный Simulated Annealing) и `QB_F1` (самый быстрый брутфорсер), мы предоставляем готовый контейнер с полной версией библиотеки. Этот контейнер оптимизирован для работы c GPU облаке cloud.ru и доступен на нашем маркетплейсе.

**Преимущества полной версии:**
*   **Доступ к эксклюзивным солверам**: `MSSA` и `QB_F1`.
*   **Максимальная производительность**: Полная оптимизация под наше железо.
*   **Простота использования**: Не требуется ручная установка и настройка.

Чтобы запустить полную версию, разверните наш контейнер на арендованных GPU. Подробные инструкции и ссылка на контейнер доступны на маркетплейсе:

## 🏗️ Архитектура

### 📋 Классы проблем
*   `TSP`: Задача коммивояжера.
*   `MaxCut`: Задача максимального разреза графа.
*   `RandomQUBO`: Случайная QUBO-матрица.
*   `Just_Q`: Задача из готовой матрицы Q.

### 🎯 Классы солверов
*   `QBF`: Эффективный брутфорс на CPU/GPU.
*   `QB_F1`: Самый быстрый брутфорсер (int16, GPU). **Доступен в полной версии.**
*   `MSSA`: GPU-ускоренный Simulated Annealing (до 12k+ переменных). **Доступен в полной версии.**
*   `Parallel`: Обертка для запуска на нескольких устройствах.

### 💡 Решения (`Solution`)
Воспроизводимый результат работы солвера. Содержит задачу, параметры солвера, решение и исследовательские метрики.

```
│       ├── abc/            # Общие классы
│       │   ├── problem_abc.py # Общий класс для всех типов задач
│       │   └── solver_abc.py # Общий класс для всех солверов

│       │   ├── random_qubo.py # Случайная QUBO-матрица
│       │   ├── reduced_problem.py # Обертка для фиксации нескольких переменных
│       │   ├── tsp.py      # Задача коммивояжера

│       │   ├── qbf1.py     # Bruteforce на CUDA, самый быстрый
│       │   └── scheduler.py # Мультипроцессный диспетчер

```

## 🤝 Внесение вклада

Основной способ внести вклад — добавить новый класс задачи. Для этого необходимо унаследовать ваш класс от `ProblemABC` и реализовать его методы. Это позволит другим исследователям легко использовать и сравнивать вашу разработку.
Еще один способ - добавлять известные бенчмарки.
