# pyqubo_bnb

Библиотека для точного решения задач квадратичной неограниченной бинарной оптимизации (QUBO) с помощью алгоритма **branch-and-bound**.

## Особенности

- **Точное решение** — находит глобальный оптимум, а не приближённое решение
- **Масштабируемость** — позволяет решать задачи большего размера, чем полный перебор (brute force), благодаря отсечению неперспективных ветвей дерева поиска
- **Параллелизация** — использует OpenMP для многопоточного выполнения на **CPU**
- **Python-интерфейс** — удобный вызов из Python через Cython-обёртку

### Описание файлов

| Файл | Описание |
|------|----------|
| `qubo_bnb.hpp` | Заголовочный файл C++: структура `QuboResult` и объявление функции `solve_qubo_bnb_parallel()` |
| `qubo_bnb.cpp` | Основная реализация на C++: класс `Solver` с методами `lower_bound()`, `greedy_completion()`, `choose_branch_var()`, `dfs()`, `build_frontier()`. Алгоритм использует оценку нижней границы для отсечения ветвей и эвристическое завершение для быстрого нахождения хороших решений |
| `pyqubo_bnb.pyx` | Cython-обёртка: функция `solve_qubo_omp()` для вызова из Python. Принимает матрицу QUBO как NumPy-массив, возвращает словарь с результатом |
| `setup.py` | Конфигурация сборки: компиляция C++ кода с OpenMP, создание разделяемой библиотеки (.so) для Python |
| `requirements.txt` | Зависимости Python: NumPy и Cython |

## Требования

- Python 3.8+
- NumPy

- C++ компилятор с поддержкой OpenMP (g++, clang)

## Использование

```python
import numpy as np
from pyqubo_bnb import solve_qubo_omp

# Создайте матрицу QUBO (симметричную или нет)
Q = np.array([
    [ 1.0, -2.0,  0.5],
    [ 0.0,  3.0, -1.0],
    [ 0.0,  0.0,  2.0],
], dtype=np.float64)

# Решите задачу
result = solve_qubo_omp(Q, split_depth=4, num_threads=8)

# Результаты
print("Objective value:", result["objective_value"])
print("Assignment:", result["assignment"])
print("Explored nodes:", result["explored_nodes"])

# Проверка: x @ Q @ x должен совпадать с objective_value
x = result["assignment"]
print("Verification:", x @ Q @ x)
```

## Параметры функции `solve_qubo_omp`

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `Q` | `np.ndarray` | — | Матрица QUBO размера N×N (float64) |
| `split_depth` | `int` | 4 | Глубина разделения дерева для параллелизации |
| `num_threads` | `int` | 4 | Количество потоков OpenMP |

## Возвращаемое значение

Словарь с тремя ключами:

- `"objective_value"` (float) — минимальное значение целевой функции x^T Q x
- `"assignment"` (np.ndarray) — вектор бинарных решений (0 или 1)
- `"explored_nodes"` (int) — количество исследованных узлов дерева поиска

## Рекомендации по параметрам

- **`split_depth`**: Увеличивайте для больших задач (N > 30). Значение 4–6 обычно оптимально. Слишком малое значение не даст достаточного параллелизма, слишком большое — создаст избыточное количество узлов.
- **`num_threads`**: Устанавливайте равным количеству физических ядер CPU для максимальной производительности.

## Алгоритм

Алгоритм branch-and-bound для QUBO работает следующим образом:

1. **Оценка нижней границы** (`lower_bound`) — вычисляет минимально возможное значение целевой функции для частичного назначения переменных
2. **Эвристическое завершение** (`greedy_completion`) — быстро находит хорошее полное решение для обновления текущей лучшей границы
3. **Выбор переменной для ветвления** (`choose_branch_var`) — выбирает переменную с наибольшим влиянием на целевую функцию
4. **Поиск с отсечением** (`dfs`) — рекурсивно исследует дерево, отбрасывая ветви, где нижняя граница хуже текущего лучшего решения
5. **Параллелизация** — дерево разделяется на глубине `split_depth`, и каждая ветвь обрабатывается отдельным потоком OpenMP
